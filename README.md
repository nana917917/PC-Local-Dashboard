# PC Local Dashboard

Windows PCの「電力・電気代・容量・PC状態」を、1つの日本語ローカル画面で確認するダッシュボードです。

- 電力はWattSealがWindows起動中に自動記録します（このアプリ自身は常駐しません）
- 容量スキャンは本人がボタンを押した時だけ実行します
- PC状態は画面を開いている時だけ取得します
- データは`%LOCALAPPDATA%\PCPowerHistory`に保存し、外部へ送信しません
- 表示用サーバーは初期状態で`127.0.0.1`限定。設定で同一LAN内のスマホ閲覧を有効にできます（**LAN側は読み取り専用**）
- ブラウザーを閉じて約10分で表示サーバーを終了します（設定で「LAN閲覧中は維持」を選んだ場合だけ常駐します）

## セットアップ

1. ZIPを右クリックし「すべて展開」します。ZIP内から直接実行しないでください。
2. 展開先の`SETUP.cmd`をダブルクリックします。
3. Windowsの確認画面が出た場合は内容を確認して許可します。
4. 完了後、デスクトップの`PC Local Dashboard`を開きます。

必要条件はWindows 10/11 64bit、Node.js 22.5以降、初回セットアップ時のインターネット接続です。計測エンジンは、互換性を確認済みのWattSeal v1.0.2を公式GitHubから取得し、固定SHA-256で検証します。

## 画面の構成

上部の期間（今日・昨日・7日・30日・今月・先月・今年・1年・全期間・カスタム）を切り替えると、料金・グラフの粒度・比較対象・表がすべて連動します。

| タブ | 内容 |
| --- | --- |
| 概要 | 現在の推定電力、選択期間の料金・電力量・使用時間、いまの負荷状態、前日・同期間との比較、今月の着地予測、直近のグラフ |
| 履歴・料金 | 電力(W)／電力量／料金／累積の切り替え、ホバー詳細、前期間・前年同期間との比較、数値の確認表、ピーク・アイドル・記録のない時間、24時間パターン、日別ヒートマップ、部品・アプリ別の内訳（推定） |
| セッション | PCが起動していた区間ごとの時間・平均/最大W・推定kWh・推定料金・主なアプリ・アイドル時間 |
| PC状態 | CPU・GPU・メモリ・ストレージ・ネットワーク・稼働時間・温度・ファン・クロック・ドライブ状態（取得できない項目は「未取得」「未対応」と表示） |
| 容量 | 既存の容量マップ（手動スキャン、ツリーマップ、用途分類、前回差分）＋スキャン状態・最終スキャンの要約（マップはPC側でのみ表示） |

## データの読み方（重要）

- 電力・料金はすべて**WattSealの内部センサー記録から求めた推定値**です。壁コンセントで測る機器ではないため、電力会社の請求額とは一致しません。
- 料金は「推定kWh × 設定した電力単価」で計算しています。単価は設定画面で変更できます。
- 計算式は「（WattSeal値 × センサー補正倍率 × 校正係数）＋ マザーボード等の固定W ＋ モニターW」です。
- **記録なし（欠損）と0Wは区別します。** PC停止・スリープ・計測停止の時間は0円として加算せず、グラフでも線をつながず、「記録なし」と表示します。センサーが0Wを報告した区間は「0Wとして記録」と表示します。
- 古い期間はWattSeal側で1時間ごとの平均に畳まれています。この区間は「1時間平均の記録」と表示し、使用時間は概算になります。
- 15秒より古い記録や1時間平均の記録は「現在値」として表示しません。
- **比較できないときは増減率を出しません。** 比較対象の記録が不足している場合は理由を表示します。期間の長さが違う場合は「単純比較」と表示します。
- **アプリ別の電力は推定配分です。** PC全体の電力とアプリの使用状況から求めた割合で、アプリ単体を測った値ではありません。未分類は「その他・未分類」として残し、アプリ別の合計がPC全体と一致するようには表示しません。

## 設定・データ管理

- 計算: 電力単価、センサー補正倍率、実測との校正係数、固定W、モニターW、月間料金の目安
- 表示: 最初に表示する期間、電力量の単位（kWh／Wh）、現在値の更新間隔、電力の通知しきい値
- 分類: ゲーム判定キーワード、アプリごとの分類（`chrome.exe = browser`形式）
- データ: CSV／JSON出力（表示期間）、DBバックアップ、容量スキャン結果の削除、**指定期間だけ削除**、全履歴の初期化、設定の初期化（履歴初期化とは別操作）
- LAN: スマホ閲覧の有効化、サーバー維持（常駐）の選択、接続URL、サーバー稼働状態
- ログ: 通常ログ／詳細ログの表示

削除操作は必ず確認を求めます。指定期間の削除・全履歴の初期化は元に戻せないため、先にCSVまたはDBバックアップを保存してください。

## スマホから見る（同一LAN内・読み取り専用）

1. PCとスマホを同じ家庭内Wi-Fiへ接続します。
2. PC側で「設定・データ」→「LAN」→「同一Wi-Fiのスマホから開く」を有効にし、保存して再起動します。
3. 設定画面に表示された`http://192.168.x.x:17891`のようなURLをスマホで開きます。
4. Windowsファイアウォールが確認を出した場合は、プライベートネットワークだけを許可します。

### 接続できる範囲

- 接続を許可するのは、**このPCのネットワークインターフェースと同じサブネット**の端末だけです。たとえばPCが`192.168.1.5/24`なら、`192.168.1.0/24`の端末だけが接続できます。
- 以前のように「家庭内LANでよく使われる広い範囲（10.0.0.0/8、100.64.0.0/10など）」をまとめて許可することはしません。100.64.0.0/10はISPの共有アドレスやVPNでも使われるため、**PC自身がそのサブネットにいるときだけ**、そのサブネット（例: `100.64.1.0/24`）が許可対象になります。
- 仮想アダプター（WSL・Hyper-V・Docker・VPNなど）は既定では許可しません。
- 別のサブネットからも見たい場合だけ、設定画面の「追加で許可するネットワーク」にCIDR（例: `192.168.10.0/24`）を明示的に追加してください。

スマホ（LAN側）からできるのは**表示と読み取り（CSV/JSON保存）だけ**です。設定変更・削除・再起動・DBバックアップはPC側の画面からのみ実行できます。LAN側へ返す内容からは、DBやログの絶対パス・PC名・ドライブのボリューム名を除外しています。容量マップ（フォルダ名・パスを扱う画面）はPC側でのみ表示できます。

### サーバーの動き

- 既定: ブラウザーを閉じて約10分アクセスがないと、表示サーバーは終了します。スマホから見るときは、PC側でダッシュボードを開いておく必要があります。
- 設定で「LAN閲覧中はサーバーを維持する」を有効にした場合だけ、表示サーバーが常駐します（Windowsの自動起動には追加しません）。
- インターネット公開は行いません。ルーターのポート開放もしないでください。

### スマホのショートカット（PWAについて）

- スマホのブラウザーで「ホーム画面に追加」すると、次回から開きやすくなります。これは**補助的なショートカット**です。
- **オフラインでは動作しません。** 画面は常にPC側のサーバーから取得するため、PCの表示サーバーが動いていないときは開けません。
- インストール（アプリとしての追加）は、ブラウザーの種類や接続方法によっては行えません。`http://`のLANアドレスではインストールが制限される場合があります（HTTPSのページや`localhost`でのみインストールできるブラウザーがあります）。
- そのため、Service Workerは登録していません（オフラインキャッシュも行いません）。

## ログ

- 通常ログ: `%LOCALAPPDATA%\PCPowerHistory\app\logs\app.log`（人が読むための要約）
- 詳細ログ: `%LOCALAPPDATA%\PCPowerHistory\app\logs\debug.log`（エラー種別・発生箇所・HTTPステータス・センサー取得結果などの技術情報、JSON形式）
- どちらもユーザー名・PC名・絶対パスは`%USERNAME%`・`%COMPUTERNAME%`・`%APP_DIR%`へ置き換えて保存します。
- 画面からは「設定・データ」→「ログ」で確認できます。

## 保存場所とアンインストール

アプリとデータは`%LOCALAPPDATA%\PCPowerHistory`へ配置されます。ダウンロードフォルダ側の展開物は、セットアップ後に削除して構いません。

Windowsの「インストールされているアプリ」に`PC Local Dashboard`として登録されます。そこから、またはインストール先の`アンインストール.cmd`から削除できます。アンインストール時に記録データも消すか選択できます（記録データを残した場合、次回セットアップでそのまま引き継ぎます）。

## 計測の考え方

WattSealはCPUのRAPL、GPUのベンダーAPIなど、取得可能な内部センサーを利用します。RAM・ディスク・ネットワーク、基板・電源損失など一部は推定です。コンセントから測る機器ではないため、請求額と完全一致するものではありません。

将来の拡張候補として、壁コンセント実測値との差分表示・アイドル時オフセットの自動調整を仕様に残しています（`SPECIFICATION.md`）。実装は今回行っていません。

## v0.12.0の変更（概要）

- データ取得状態の明示（記録中／最終取得／古い／未接続／一部欠損／推定値／比較不能）
- 記録なし・0W・未対応を区別して表示
- 期間とグラフ粒度・比較・表の完全連動（今日／昨日／7日／30日／今月／先月／今年／1年／全期間／カスタム）
- 前期間・前年同期間の比較（記録が足りないときは増減率を出さない）
- ホバー詳細と数値の確認表、日別ヒートマップ、24時間パターン、ピーク・アイドル・記録のない時間の抽出
- セッション分析の改善（アイドル時間・主なアプリ・状態）
- アプリ分類の手動設定、CSV／JSON出力、DBバックアップ、指定期間の削除
- LAN側の読み取り専用化、サーバー稼働状態の表示、任意のサーバー維持モード
- 通常ログと詳細ログの分離

## 配布物の作り方（開発者向け）

```
npm test                     # 構文・静的チェック・自動テスト
node tools/build-release.js --zip   # dist\PC-Local-Dashboard-v<version>.zip を作成
```

`tools/build-release.js`は、DB・ログ・PID・`WattSeal.exe`・`node_modules`・`.env`・ZIPの重複などを除外し、混入がないことを確認してからZIPを作ります。除外対象は`SETUP.cmd`でインストールする側でも持ち込まれません。
