# PC Local Dashboard

Windows PCの「電力・容量・PC状態」を、1つの日本語ローカル画面で確認するダッシュボードです。

- 電力はWattSealがWindows起動中に自動記録
- 容量スキャンは本人がボタンを押した時だけ実行
- PC状態は画面を開いている時だけ取得
- データは`%LOCALAPPDATA%\PCPowerHistory`に保存し、外部へ送信しない
- 表示用サーバーは初期状態で`127.0.0.1`限定。設定で同一Wi-Fi内のスマホ閲覧を有効化できます
- ブラウザーを閉じて5分後に表示サーバーを終了

## セットアップ

1. ZIPを右クリックし「すべて展開」します。ZIP内から直接実行しないでください。
2. 展開先の`SETUP.cmd`をダブルクリックします。
3. Windowsの確認画面が出た場合は内容を確認して許可します。
4. 完了後、デスクトップの`PC Local Dashboard`を開きます。

必要条件はWindows 10/11 64bit、Node.js 22.5以降、初回セットアップ時のインターネット接続です。計測エンジンは、互換性を確認済みのWattSeal v1.0.2を公式GitHubから取得し、固定SHA-256で検証します。

### スマホから見る

1. PCとスマホを同じ家庭内Wi-Fiへ接続します。
2. PC側で「設定・データ」→「同一Wi-Fiのスマホから開く」を有効にします。
3. 再起動後に表示される`http://192.168...:17891`のURLをスマホで開きます。
4. Windowsファイアウォールが確認を出した場合は、プライベートネットワークだけを許可します。

この機能はインターネット公開用ではありません。ルーターのポート開放は行わないでください。スマホからは読み取りだけでなく設定・削除操作も可能になるため、信頼できる家庭内ネットワークでのみ使用してください。

## 電力タブ

- 現在の推定W数、料金、kWh、記録時間
- 現在W数を1時間続けた場合の推定料金
- 今いちばん使っている部品・アプリ
- 直近5分／15分／60分のリアルタイム折れ線
- 今日・7日・今月・30日・90日・1年・全期間の電気代履歴
- 選択期間の累積料金折れ線
- 直前の同期間との料金比較
- 累積グラフへの直前期間の重ね合わせ（比較期間の記録が十分な場合）
- グラフ上のホバー詳細と水平な自動間引き時間軸
- 最も料金が高かった時間／日の自動抽出

7日以上の期間を選ぶと、グラフは自動で累積料金へ切り替わります。リアルタイムW、時間／日別料金へはいつでも手動で戻せます。
- 部品別、用途別、アプリ別の推定内訳
- 今回／前回のPC使用、今月の着地予測
- 起動セッション履歴
- 表示期間または全期間のCSV出力

スリープ・電源OFF中はPCが計測できないため線が途切れ、その時間の料金は加算されません。PCを起こしたままにする処理はありません。

## 容量タブ

- ドライブ／フォルダを本人が選んで手動スキャン
- 容量ツリーマップ
- ゲーム、動画、音楽、Windows・アプリ等の用途分類
- 大容量フォルダ／ファイル一覧
- 同じ場所を再スキャンした場合の前回差分

スキャンは読み取り専用です。ファイル本体の削除機能はありません。

## PC状態タブ

- CPU、GPU、メモリ使用率
- GPU温度、GPU電力（`nvidia-smi`で取得可能な場合）
- PC稼働時間
- ドライブ空き容量
- WattSealの動作・最終記録時刻
- WattSeal DBに使用率列がある場合の直近15分／今日の履歴

センサーが取得できない環境では、その項目だけを「取得対象外」と表示します。

## 設定・データ管理

- 電力単価、センサー倍率、基板等の固定W、モニターW
- 任意の月間PC電気代目安と、着地予測の超過／余裕表示
- ゲーム分類キーワード
- DB容量、記録開始日、記録日数
- 全期間CSVバックアップ
- 容量スキャン結果の手動削除
- 電力履歴の手動初期化
- 計算設定の初期化

履歴の自動削除、強制更新、勝手なアップデートは行いません。更新機能はGitHub公開先が決まった後に、本人が押す「更新を確認」方式で追加できます。

## 保存場所とアンインストール

アプリとデータは`%LOCALAPPDATA%\PCPowerHistory`へ配置されます。ダウンロードフォルダ側の展開物は、セットアップ後に削除して構いません。

Windowsの「インストールされているアプリ」に`PC Local Dashboard`として登録されます。そこから、またはインストール先の`アンインストール.cmd`から削除できます。アンインストール時に記録データも消すか選択できます。

## 計測の考え方

WattSealはCPUのRAPL、GPUのベンダーAPIなど、取得可能な内部センサーを利用します。RAM・ディスク・ネットワーク、基板・電源損失など一部は推定です。コンセントから測る機器ではないため、請求額と完全一致するものではありません。

## v0.11.0の変更

トップ画面を「現在の状態・期間料金・主な要因」に絞り、部品・アプリ・セッションの詳細を展開式へ整理しました。古い計測値を現在値として表示しないようにし、使用率履歴の欠損を0として描画しないようにしました。同一Wi-Fiのスマホ閲覧、ドライブ健康状態の取得、複数GPUの集約、セットアップログの簡潔化、WattSeal固定SHA-256検証を追加しました。

## v0.10.0の変更

長期表示を強化し、90日・1年・全期間を選んで累積料金を折れ線で確認できるようにしました。時間別料金の斜めラベルを廃止し、画面幅に合わせて水平ラベルを自動で間引きます。グラフへカーソルを合わせると日時、料金、kWh、平均W、記録時間を表示します。直前期間比、期間内の最大料金、現在Wを1時間続けた場合の料金も追加しました。

## トラブル確認

`CHECK.cmd`を実行すると、Node.js、WattSeal、ダッシュボード、DB、計測プロセス、セットアップログを確認できます。
